# Smart Parking Backend

Mock Express backend for the Smart Parking System frontend integration.

## Setup

```bash
npm install
npm run dev
```

## URLs

- API health: `http://localhost:3000/api/health`
- Swagger UI: `http://localhost:3000/api-docs`

## Notes

This scaffold uses in-memory seed data only. Data resets when the server restarts, or by calling `POST /api/debug/reset`.
